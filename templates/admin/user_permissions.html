User Permission Overrides

Overrides replace the default role-based decision for the selected user. "Allow" grants even if the role does not; "Deny" blocks even if the role grants; "Inherit" removes any override and falls back to the role.

How User Permission Overrides Work

  • User overrides take precedence over role permissions
  • Superadmins bypass all checks regardless of settings
  • Allow (✓) grants permission even if role denies it
  • Deny (✗) blocks permission even if role allows it
  • Inherit (default) falls back to user's role permissions
  • To remove an override, select "Inherit" and click Update Permissions
